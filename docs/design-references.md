# Design references and visual credits

## Layout

The profile gives equal space to data analytics and data engineering. It opens with a motion graphic: a staged name-and-intro reveal alongside a small data-workflow scene. Four linked pill controls sit below it. The rest follows an editorial flow: short introduction, one featured Olist project, three concise selected-project notes, a scrolling skills ribbon, and matching activity panels.

Portfolio copy is native Markdown and HTML. The motion header holds the name and concise focus line; project descriptions remain native text for readability in GitHub's light and dark themes and on phones.

## Motion and GitHub activity

The header stages the name, role, intro, and workflow illustration over 600ms. The skills ribbon scrolls continuously at a calm fixed rate. The Olist preview assembles once over 0.45 seconds. Static alternatives support reduced motion. There are no moving light bars, border sweeps, or animated link arrows.

- [GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats): account overview, with rank and star row hidden. `card_width=450` and `line_height=31` produce a 450 × 200 image.
- [GitHub Readme Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats): contribution totals and streaks. `card_width=450` and `card_height=200` match the overview dimensions.

Both images display at 360 × 160 on desktop, scale proportionally on phones, and use the same navy background, border, and corner radius. Both switch to service URLs with animations disabled when reduced motion is requested. The services cache GitHub responses; totals can differ by reporting period and refresh time. These are activity metrics, not measures of skill.
