# Design references and visual credits

The profile uses a coordinated navy, sky-blue, and violet palette, recognizable technology logos, compact project visuals, and real GitHub activity widgets.

## Profile references

- [DenverCoder1](https://github.com/DenverCoder1): grouped tool icons, project links, streaks, and activity cards.
- [Anurag Hazra](https://github.com/anuraghazra): concise personal introduction, project highlights, and GitHub statistics.
- [Awesome GitHub Profile README](https://github.com/abhisheknaiidu/awesome-github-profile-readme): reference collection for established profile layouts.
- [Skill Icons](https://github.com/tandpfun/skill-icons): recognizable, consistently sized technology tiles. This profile builds its own labeled tiles from the logo sources below.

## Logo sources

- [SVG Logos by gilbarbara](https://github.com/gilbarbara/logos): Python, pandas, PostgreSQL, Azure, Power BI, Snowflake, dbt, Git, GitHub, and Looker. Collection distributed under CC0; logos remain the property of their respective owners.
- [Devicon](https://github.com/devicons/devicon): SQL Server (`icons/microsoftsqlserver/microsoftsqlserver-original.svg`), MIT license.
- [Microsoft Office CDN](https://res.cdn.office.net/files/fabric-cdn-prod_20230815.002/assets/brand-icons/product/svg/excel_48x1.svg): Excel product icon, copyright Microsoft.

Original logo files are in `assets/icons/`; labeled tool tiles and project illustrations are generated by `scripts/build_profile_assets.py`. Logos identify the technologies used and do not indicate endorsement.

## Live GitHub visuals

- [GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats): account overview, with the rank and star row hidden.
- [GitHub Readme Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats): contribution totals and streaks.
- [GitHub Profile Summary Cards](https://github.com/vn7n24fzkq/github-profile-summary-cards): the contribution chart.

All widgets use the username `pruthviiraj`. They query GitHub through their own services and cache their responses, so totals can differ by reporting period and refresh time. These are activity metrics, not measures of skill. No fabricated counts or proficiency percentages are used.

## Content evidence

The Olist model count and prototype status were checked against the public repository's staging models and extraction code. Sales report details come from the public Excel project. Warehouse architecture comes from the CRM/ERP repository. Education, operations experience, and HR dashboard figures are retained from the existing profile.
