# Design references and visual credits

## Layout

The profile gives equal space to data analytics and data engineering. It opens with a transparent motion header rather than a large panel: staged name-and-intro text sits beside three parallel animated lines. Four linked pill controls sit below it. The rest uses structured About bullets, parallel toolkit lanes, a small activity motion graphic, matching activity panels, and four equal project tracks at the bottom.

Portfolio copy is native Markdown and HTML. Motion assets supply the name, concise focus line and decorative tracks; project descriptions and the structured About summary remain native text for readability in GitHub's light and dark themes and on phones.

## Motion and GitHub activity

The header stages the name, role and intro over 600ms. The toolkit and project visuals use low-amplitude parallel lane movement; the activity bars draw once. Static theme-specific alternatives support reduced motion. There are no moving light bars, border sweeps, or animated link arrows.

- [GitHub Readme Stats](https://github.com/anuraghazra/github-readme-stats): account overview, with rank and star row hidden. `card_width=450` and `line_height=31` produce a 450 × 200 image.
- [GitHub Readme Streak Stats](https://github.com/DenverCoder1/github-readme-streak-stats): contribution totals and streaks. `card_width=450` and `card_height=200` match the overview dimensions.

Both images display at 360 × 160 on desktop, scale proportionally on phones, and use the same navy background, border, and corner radius. Both switch to service URLs with animations disabled when reduced motion is requested. The services cache GitHub responses; totals can differ by reporting period and refresh time. These are activity metrics, not measures of skill.
